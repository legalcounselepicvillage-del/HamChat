# HamChat

تطبيق دردشة عربي بسيط يعمل فورياً باستخدام Node.js وExpress وSocket.IO. هذه نسخة أولية تستخدم غرفاً عامة وتخزن الرسائل في الذاكرة فقط.

## التشغيل

تحتاج إلى Node.js 18 أو أحدث.

```bash
npm install
npm start
```

ثم افتح [http://localhost:3000](http://localhost:3000) في المتصفح. افتح الموقع في نافذتين أو جهازين واختر اسم الغرفة نفسه لتجربة المحادثة.

للتطوير مع إعادة تشغيل تلقائية:

```bash
npm run dev
```

## ملاحظات

- الرسائل لا تُحفظ؛ تختفي عند إعادة تشغيل الخادم.
- الغرف حالياً عامة ولا يوجد تسجيل دخول أو تشفير خاص بالتطبيق.
- قبل النشر، أضف حماية من الإساءة وحدوداً لمعدل الرسائل، ثم استخدم HTTPS وخدمة تخزين مناسبة.

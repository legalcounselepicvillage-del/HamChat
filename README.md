# HamChat

تطبيق دردشة عربي فوري مع إنشاء حساب وتسجيل دخول. يستخدم Node.js وExpress وSocket.IO وSQLite.

## التشغيل

تحتاج إلى Node.js 18 أو أحدث.

```bash
npm install
npm start
```

ثم افتح [http://localhost:3000](http://localhost:3000). أنشئ حساباً ببريد إلكتروني وكلمة مرور لا تقل عن 10 أحرف، ثم اختر غرفة. يمكنك فتح الموقع في نافذتين لتجربة الدردشة.

للتطوير مع إعادة تشغيل تلقائية:

```bash
npm run dev
```

## الحسابات والأمان

- تُحفظ الحسابات في `data/hamchat.sqlite`، وتُخزن كلمات المرور باستخدام bcrypt؛ لا تُحفظ كلمات المرور كنص واضح.
- تُحفظ جلسات الدخول في SQLite، مع ملف تعريف ارتباط `HttpOnly` و`SameSite=Lax`، وتُستخدم الجلسة نفسها للتحقق من اتصال Socket.IO.
- يُحد عدد محاولات التسجيل وتسجيل الدخول. استخدم HTTPS في الإنتاج.
- عند النشر، عيّن `SESSION_SECRET` إلى قيمة سرية عشوائية طويلة، واضبط `NODE_ENV=production`. لا تشارك هذا السر أو تضعه في المستودع.
- غيّر `DATA_DIR` إذا كانت منصة الاستضافة توفر مجلداً دائماً للبيانات؛ قواعد SQLite تحتاج إلى تخزين دائم كي تبقى الحسابات بعد إعادة النشر.

## ملاحظات

الغرف عامة والرسائل لا تُحفظ. هذه نسخة أولية؛ أضف سياسات نسخ احتياطي ومراقبة وضوابط إساءة الاستخدام المناسبة قبل إطلاقها على نطاق واسع.
